# CGAL orientation repair contract

Status: on 2026-11-10, the native worker built against the installed CGAL prefix and all six orientation checks passed. The `profile-portable` desktop produced current CGAL L0–L3 (`da45b5b513ff4c8e89e31c7460fd0a31`), L4 (`af04763c46824ba8a90685f93d98966f`), orientation L5 (`a2d56188d3524cb99596a47e9a1d65d7`), and orientation L6 (`0040d73900a5478581c6c97f2f5f2ad8`) records.

`cgal.repair-orientation` now advertises the distinct `mesh.orient` capability. The historical L5–L6 records that advertised `mesh.repair` remain readable as historical records, but their source fingerprint and catalog identity are stale; they are not promoted into the new capability. The version 2 case manifest pins inward and outward tetrahedron, cube, octahedron, and affine tetrahedron inputs, plus open, disconnected, nonmanifold, and degenerate rejections. The live scope report pins each request, result, input and accepted output hash. Its verifier checks the exact triangle winding against the authored outward source and refuses changed worker, adapter, fixture, source, or result bytes. Run `python tools/scientific_cgal_orientation_scope.py run --worker <devshell_cgal_orientation.exe> --prefix <CGAL prefix> --output-root <evidence directory>`.

The worker accepts one registered, hash-checked OBJ copy up to 32 MiB. It requires a readable triangle manifold with at most 100,000 faces, no degenerate triangles or self-intersections, and one connected closed volume. It reverses face winding only when the input is inward. The output is a new OBJ in the owned run directory. An open surface, disconnected volume or invalid mesh must fail without an output artifact. The operation does not fill holes, remove degeneracies, or reconstruct polygon soups.

The managed adapter uses the shared version 1 JSON request/result envelope and executes the dedicated `devshell_cgal_orientation.exe` with argv. A successful result must report a closed outward volume and advertise `mesh.orient`; failed results advertise no validated capability or output. The launcher owns the CMake build, worker process, timeout, cancellation, logs and immutable run fingerprint. The source fingerprint includes the worker, adapter, contract, fixtures and qualification verifier.

`l5.cgal-orientation` is a separate fixed-fixture gate. It pins current CGAL L0–L4 support, repairs the authored inward unit tetrahedron, and rejects the authored open square. The positive OBJ is independently parsed for four vertices, four faces, the six closed edges, the original unit tetrahedron coordinates, and positive signed volume `1/6`. The qualification record pins both requests, results, fixture hashes and the output hash. A changed output or case result invalidates the record. This grants only `mesh.repair` L5 for the named fixtures; it does not grant L6–L9, broker export or MATH3D product promotion.

`l6.cgal-orientation` replays both fixed L5 cases with current L0–L5 support. It requires the new positive OBJ hash, input hashes, worker contract, and environment to match the selected orientation L5 baseline. An independent OBJ reload verifies four vertices, four triangles, closed topology, unit tetrahedron bounds, and positive signed volume `1/6`. The L6 record pins the baseline and reload hashes. It does not qualify broader inputs or grant L7–L9.

Hole repair has its own bounded worker, managed L5–L9 chain, and product contract. Orientation qualification remains separate fixed-fixture evidence; it does not promote arbitrary repair or broker capability.
