# Chapter 12 Python computational companion

Run from the repository root:

```bash
PYTHONPATH=examples/python/ch12 python3 -m unittest examples/python/ch12/test_companion.py
PYTHONPATH=examples/python/ch12 python3 examples/python/ch12/generate_companion.py
```

The generator writes eight deterministic vector-PDF figures, a JSON summary,
and a CSV diagnostic table to `generated/ch12/computational/`.
