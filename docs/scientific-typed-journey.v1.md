# Scientific typed journey v1

The target demonstration is a nine-stage chain: register two source meshes, validate each, run CGAL Boolean, generate a Gmsh mesh, inspect with VTK, measure with SciPy, import typed geometry and measurement into pulled MATH3D, save/export, then cold-reopen in a new process. `schemas/scientific-typed-journey.v1.json` fixes stage order, operation IDs, and input/output roles.

The independent `tools/scientific-broker/verify_typed_journey.py --bundle <directory>` checks the `journey.json` manifest and local stage evidence. It requires different source hashes for A and B, closed/manifold/positive-volume topology records for both, exact artifact bytes and SHA-256, source snapshot and consumer commit bindings, explicit length and measurement units, one right-handed coordinate frame, monotonic generation numbers, ordered parent relations, and byte-identical save/export artifacts after a new-process reopen. Paths must remain inside the bundle; symlinks and files larger than 64 MiB are rejected. It returns `verified-artifact-relations-only` deliberately: the verifier cannot itself prove that an algorithm or desktop action ran. Live managed desktop and broker evidence, followed by a trusted signed release bundle, supply that proof.

Each stage has `id`, `state`, `operation`, unique `runId`, ordered `inputs`, ordered `outputs`, and hashed `evidence`. Its evidence JSON binds `runId`, `operation`, `state`, `sourceCommit`, `sourceSnapshotSha256`, `inputHashes`, and `outputHashes`. MATH3D stages additionally bind `consumerCommit`. Each output records `id`, relative `path`, `bytes`, `sha256`, `mediaType`, `frame`, `lengthUnit`, `generation`, `parents`, and `producedBy`. The `scipy` result records a finite value and tolerance in `m3` or `mm3` matching the declared length unit. The `cold-reopen` result must record `newProcess: true`.

The contract is an acceptance boundary, not a claim that the whole chain is implemented. A completed bundle needs actual typed Gmsh Boolean-surface intake, VTK result transport, SciPy measurement, MATH3D import, and installed desktop evidence before it can pass the release gate.
