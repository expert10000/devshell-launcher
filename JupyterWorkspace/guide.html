DevShell / Jupyter Studio

Think in cells.

A small, reproducible notebook workspace for learning, data exploration, symbolic mathematics, and 3D experiments. Everything begins from the DevShell task list.

Mode of use

1

Select the profile

In DevShell choose desktop two, then select Jupyter Studio.

2

Prepare Python once

Run Jupyter - Install Environment. It installs JupyterLab and the libraries used by these notebooks.

3

Start the server

Run Jupyter - Start Lab. Keep that terminal open while working.

4

Open the workspace

Run Jupyter - Open Lab, or use one of the direct notebook tasks.
