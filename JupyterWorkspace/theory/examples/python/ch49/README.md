# Chapter 49 computational companion

Run `python -m pytest -q test_correlated_matter_companion.py` from this directory for the exactly 30 regression tests. Run `python generate_figures.py` from this directory (or `python examples/python/ch49/generate_figures.py` from the repository root) to regenerate the nine vector PDF diagnostics.

The companion deliberately separates scaling diagnostics, Green-function conditioning, gauge observables, spectral decay, superconducting nodes, moire projection ratios, and driven prethermal times rather than collapsing them into a single phase classifier.
