# Theory Python Lab

Open `INDEX.ipynb` in JupyterLab for the chapter launchers. The complete source folder is in `examples/python`; all 477 original files were verified with SHA-256 in `import-manifest.json`.

Launchers run from this directory so generators using repository-relative paths write to `generated/`. Install dependencies with `python -m pip install -r requirements.txt`. The original chapter tests remain available; a full chapter suite may take longer than the import checks.
